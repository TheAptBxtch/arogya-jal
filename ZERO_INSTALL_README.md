## 🎓 **How It Works**

### **Prediction Algorithm:**
The system uses a **rule-based machine learning approach**:

1. **Vibration Analysis**
   - High vibration = Higher failure risk
   - Thresholds: >5.0 critical, >3.0 warning

2. **Current Monitoring**
   - Excessive current = Motor stress
   - Thresholds: >30A critical, >20A warning

3. **Temperature Tracking**
   - Overheating = Component failure
   - Thresholds: >100°C critical, >80°C warning

4. **Combined Factors**
   - Multiple elevated readings = Compound risk
   - Algorithm weights and combines all factors

5. **Probability Calculation**
   - Outputs: 0-100% failure probability
   - Time window: Next 72 hours
